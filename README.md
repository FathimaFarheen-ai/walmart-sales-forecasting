# Walmart Sales Forecasting & Analysis 📊

An end-to-end data analytics and sales forecasting project using Python, Machine Learning and Power BI.

## 📌 Project Overview

This project analyzes historical Walmart Superstore sales data to identify business trends, customer patterns and regional performance, and applies machine learning models for sales forecasting.

The project includes exploratory data analysis, data visualization, predictive modeling and an interactive Power BI dashboard.

## 🎯 Objectives

- Analyze historical sales and business performance
- Identify category, regional and customer-segment trends
- Explore monthly sales patterns
- Build and compare machine learning models for forecasting
- Visualize key insights through Power BI

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- TensorFlow / Keras
- Power BI
- Excel
- Jupyter Notebook

## 📊 Data Analysis

The analysis covers:

- Category-wise sales
- Regional sales performance
- Customer-segment analysis
- Profit and discount relationships
- Monthly sales trends
- Product and customer-level analysis

## 🤖 Machine Learning

Multiple models were explored and compared:

- Linear Regression
- Random Forest
- XGBoost
- Neural Networks

The best-performing model achieved an R² score of approximately **0.94** on the project evaluation.

## 📈 Power BI Dashboard

An interactive Power BI dashboard was created to visualize sales trends and business insights.

The `.pbix` dashboard file is included in this repository.
